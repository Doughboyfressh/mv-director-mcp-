# Music Video Director - setup

1. Wait until the setup finishes (about 3-5 minutes the first time).
2. Open **CONNECTOR_URL.txt** in the file list on the left and copy the link inside. Keep it private.
3. Open the **PORTS** tab. If port 8000 does not say *Public*: long-press (or right-click) it,
   choose **Port Visibility -> Public**.
4. In a browser go to **claude.ai -> Settings -> Connectors -> Add custom connector**,
   name it *Music Video Director*, paste the link, save.
5. Start a new chat with Claude (phone app works) and say what you want to do with your video.

Next time: open github.com/codespaces and tap this codespace to wake it up. The link stays the same.
